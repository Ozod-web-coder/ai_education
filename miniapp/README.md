# Mini App администратора

Telegram Mini App для сотрудников учебного центра: список заявок, карточка ученика, статусы, поиск и фильтры.
React + Vite. Дизайн: белый фон, оранжевый акцент, шрифт Inter.

## Что умеет

| Функция | Как работает |
|---|---|
| Список заявок | имя, телефон, @username, курс, дата регистрации, статус; подгрузка по 20 |
| Карточка заявки | все данные ученика, записи в группы, цель, данные родителя для несовершеннолетних |
| Статусы | Новая, Подтверждена, Пришёл, Не пришёл, Записан на курс, Отказался |
| Подтверждение | кнопка «Связался»: ставит «Подтверждена» и время связи |
| Поиск и фильтры | поиск по имени, телефону и @username; фильтры по статусу (со счётчиками) и курсу |
| Удаление | только через шторку подтверждения; записи ученика в группы тоже удаляются, места освобождаются |
| Защита от дубликатов | предупреждение в списке («Повтор») и в карточке, если тот же телефон или @username уже есть в заявках центра |

Статусы бота («Нужен менеджер», «Прошёл тест», «Записан», «Потерян») тоже показываются: в фильтре они появляются, когда такие заявки есть.

## Запуск

```bash
cd miniapp
cp .env.example .env     # укажите VITE_CENTER_SLUG
npm install
npm run dev              # http://localhost:5173, запросы /api проксируются на http://127.0.0.1:8000
npm run build            # статика в miniapp/dist
```

Бэкенд должен работать (`python manage.py runserver`).

### Проверка в обычном браузере (без Telegram)

В `miniapp/.env` раскомментируйте `VITE_DEV_TOKEN` и вставьте access-токен сотрудника (команда указана в `.env.example`). Работает только в `npm run dev`.

## Подключение к Telegram

1. Выложите `miniapp/dist` на любой хостинг с HTTPS (Vercel, Netlify, Cloudflare Pages, nginx).
2. При сборке задайте `VITE_API_URL=https://api.example.com/api` и `VITE_CENTER_SLUG=<код центра>`.
3. В `.env` бэкенда добавьте адрес приложения в `CORS_ALLOWED_ORIGINS` и в `ALLOWED_HOSTS` адрес API.
4. В @BotFather: `/mybots` → бот → Bot Settings → Menu Button → укажите адрес Mini App.

## Как выдать доступ сотруднику

Приложение пускает только сотрудников центра. В админке Django (`/admin/` → Пользователи) у сотрудника заполните:

- **Telegram id** (узнать можно у бота @userinfobot),
- **Центр**,
- галочку **Сотрудник**.

После этого он входит в Mini App своим Telegram-аккаунтом. Остальные видят экран «Нет доступа».

## API, которым пользуется приложение

Все адреса под `/api/c/<центр>/admin/leads/`, нужен JWT сотрудника этого центра.

| Метод | URL | Что делает |
|---|---|---|
| GET | `/` | список: `?search=`, `?status=new,confirmed`, `?course=<id>`, `?page=` |
| GET | `/stats/` | сколько заявок в каждом статусе |
| GET | `/<id>/` | карточка |
| PATCH | `/<id>/` | `status`, `manager_note`, `desired_course`, `name`, `phone` |
| POST | `/<id>/confirm/` | отметить, что связались с учеником |
| DELETE | `/<id>/` | удалить заявку |
